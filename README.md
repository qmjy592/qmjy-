# 芊茗静语的专属空间 (Portal Project)

这是我的个人专属后端与前端项目，包含个人主页、AI 伴侣、小游戏、音乐盒等功能模块。

## 🛠️ 技术栈
*   前端：HTML / CSS / JavaScript
*   后端：Python (Termux 环境)
*   本地编译：llama.cpp (Android ARM64)
*   AI 服务：云端 API

## 📁 项目结构
*   `index.html` - 前端主页面
*   `my_ultimate_portal.py` - 后端服务器逻辑
*   `llama.cpp-master/` - 本地编译的推理框架
*   `music/` - 音乐资源
*   `*.json` - 个人资料、论坛、HRT等数据文件
